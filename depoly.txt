SD Prasant - Production Deployment (Docker + SSL + Port 8989)

Server:
- Public IP: http://161.97.146.14/
- Domain: https://growvyapaar.com/
- App external port: 8989 (server has other apps, so avoid common ports)

==================================================
1) One-time server setup
==================================================

sudo apt update && sudo apt upgrade -y
sudo apt install -y git docker.io docker-compose-plugin nginx certbot python3-certbot-nginx ufw
sudo systemctl enable docker
sudo systemctl start docker

# Firewall
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable

==================================================
2) Clone project on server
==================================================

sudo mkdir -p /srv/growvyapaar
sudo chown -R $USER:$USER /srv/growvyapaar
cd /srv/growvyapaar
git clone https://github.com/kriyespro/growvp.git  app
cd app

# Create env file from template
cp ev.txt .env

==================================================
3) Docker compose production notes
==================================================

Edit docker-compose.yml for production ports:
- web service ports should be:
  - "127.0.0.1:8989:8000"

This keeps Django private to localhost and exposes app through Nginx on SSL.

Optional hardening:
- Remove DB port exposure on host:
  delete/comment db ports:
  - "5432:5432"

==================================================
4) Build and run production containers
==================================================

cd /srv/growvyapaar/app
docker compose pull
docker compose build --no-cache
docker compose up -d
docker compose ps
docker compose logs -f web

==================================================
5) Nginx reverse proxy + SSL
==================================================

Create Nginx config:

sudo nano /etc/nginx/sites-available/growvyapaar.com

Paste:

server {
    listen 80;
    server_name growvyapaar.com www.growvyapaar.com 161.97.146.14;

    location / {
        proxy_pass http://127.0.0.1:8989;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Enable site:
sudo ln -s /etc/nginx/sites-available/growvyapaar.com /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

Issue SSL certificate:
sudo certbot --nginx -d growvyapaar.com -d www.growvyapaar.com

Auto-renew verify:
sudo systemctl status certbot.timer
sudo certbot renew --dry-run

==================================================
6) Django production checklist
==================================================

- DJANGO_DEBUG=False
- DJANGO_ALLOWED_HOSTS=growvyapaar.com,www.growvyapaar.com,161.97.146.14
- DJANGO_CSRF_TRUSTED_ORIGINS=https://growvyapaar.com,https://www.growvyapaar.com
- Strong DJANGO_SECRET_KEY
- Strong POSTGRES_PASSWORD
- Use gunicorn (already in docker compose command)
- collectstatic and migrate run in startup command

==================================================
7) Git workflow (local -> live server)
==================================================

Local machine:
git add .
git commit -m "deploy: production update"
git push origin main

Live server pull + deploy:
cd /srv/growvyapaar/app
git pull origin main
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose restart web

Rollback quickly (if required):
git log --oneline -n 5
git checkout <OLD_COMMIT_HASH>
docker compose up -d --build
