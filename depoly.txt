SuratBazar — Production Deploy (Docker + Nginx + SSL)
====================================================

Server IP:  159.195.52.197
Domain:     https://suratbazar.online/  (+ www)
App port:   127.0.0.1:8998 → container :8000

NOTE: https://suratbazar.online/ currently serves a marketing site.
Deploying this app will replace that origin — update DNS / Nginx
only when you are ready to cut over.

==================================================
1) One-time server setup
==================================================

sudo apt update && sudo apt upgrade -y
sudo apt install -y git docker.io docker-compose-plugin nginx certbot python3-certbot-nginx ufw
sudo systemctl enable --now docker

sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable

==================================================
2) Clone / sync project
==================================================

# Install under root home (not /srv)
mkdir -p /root/sd-sub
cd /root/sd-sub
# git clone <YOUR_REPO_URL> app
cd app

# Production secrets
cp .env.prod .env
# NEVER commit .env / .env.prod to a public repo after secrets are set

==================================================
3) Docker compose
==================================================

docker compose build --no-cache
docker compose up -d
docker compose ps
docker compose logs -f web

App listens on: http://127.0.0.1:8998  (localhost only)

==================================================
4) Nginx + SSL
==================================================

sudo nano /etc/nginx/sites-available/suratbazar.online

server {
    listen 80;
    server_name suratbazar.online www.suratbazar.online 159.195.52.197;

    client_max_body_size 20M;

    location /media/ {
        alias /root/sd-sub/app/media/;
    }

    location / {
        proxy_pass http://127.0.0.1:8998;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }
}

sudo ln -sf /etc/nginx/sites-available/suratbazar.online /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

sudo certbot --nginx -d suratbazar.online -d www.suratbazar.online
